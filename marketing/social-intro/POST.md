## 正文（抖音 / 小红书 / B 站短视频）

还在用 Markdown 写内容，效果却太单调？
想用 HTML 得到丰富的效果，写起来却太复杂？

MDS 想帮你消除这些烦恼。仍旧在写 Markdown，但是渲染出网页级的效果。

一种新的标记语言。Think in Markdown. Render in HTML.

你照常写 Markdown，只多写几个语义块；布局、动效和交互交给 MDS 渲染器，最后得到像 HTML 一样丰富美观的页面效果。

写法也很简单——先写最基础的 Markdown，再写 hero，当然也可以像 HTML 那样写 button、slider、switch 等各种控件，MDS 渲染器会立刻渲染成真正的页面。

还有多种默认主题可选，像 default、light、dark、rich；不满意也可以自己定制主题。

公开 Beta 已上线，通过下面的命令即可快速使用：

```bash
npm i -g @mds-crate/cli@next
mds edit ./page.mds
```

源代码已发布 GitHub，欢迎上手反馈。
https://github.com/ziyu/mds
