# @mds-crate/html-types

Shared TypeScript contracts for MDS HTML renderers and themes, including `HtmlTheme`, block renderers, render context, and shell interfaces.

This is a lower-level dependency. Application integrations should normally start with `@mds-crate/renderer-html`; theme authors should start with an MDS theme SDK.

See the [MDS repository](https://github.com/ziyu/mds). Licensed under Apache-2.0.
