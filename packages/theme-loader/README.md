# @mds-crate/theme-loader

Theme artifact loading, validation, composition, registry, and package resolution for MDS.

- Use the package root for Node.js file and package resolution.
- Use `@mds-crate/theme-loader/browser` for browser-safe source and registry APIs.
- Use the JSX subpaths only when authoring build-time themes.

See the [theme documentation](https://github.com/ziyu/mds/blob/main/docs/THEMES.md). Licensed under Apache-2.0.
