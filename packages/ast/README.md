# @mds-crate/ast

AST node and diagnostic contracts for MDS documents.

This is a lower-level package used by the parser, renderer, editor, and theme types. Most application integrations should start with `@mds-crate/renderer-html`.

MDS is preparing its first public beta. See the [repository](https://github.com/ziyu/mds) and [release plan](https://github.com/ziyu/mds/blob/main/docs/RELEASE_PLAN.md).
