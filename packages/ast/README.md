# @mds-crate/ast

AST node and diagnostic contracts for MDS documents.

This is a lower-level package used by the parser, renderer, editor, and theme types. Most application integrations should start with `@mds-crate/renderer-html`.

MDS `0.1.0-beta.1` is available on npm. See the [repository](https://github.com/ziyu/mds), [beta guide](https://github.com/ziyu/mds/blob/main/docs/BETA.md), and [release plan](https://github.com/ziyu/mds/blob/main/docs/RELEASE_PLAN.md).
