# @mds-crate/theme-rich

Official MDS theme for documents that need data tables, charts, technical documentation, guided sequences, galleries, and conversation layouts.

The shared `@mds-crate/blocks` package stays focused on portable UI primitives. Rich owns the higher-level compositions and their progressive enhancement while still producing a standalone theme artifact.

See the [theme documentation](https://github.com/ziyu/mds/blob/main/docs/THEMES.md). Licensed under Apache-2.0.
